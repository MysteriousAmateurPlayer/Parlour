## 十一天

这株月季是前年秋天买的小苗，品种标签早就丢了，只记得是偏橘的复色。去年一整年它只长叶子，一片花苞都没有——我一度怀疑是光照不够，差点把它送人。

今年五月二十七号，我在顶端看到第一个花苞，比米粒大一点。

| 日期 | 状态 |
| --- | --- |
| 05-27 | 顶端出现花苞 |
| 05-31 | 花苞明显膨大，外层萼片开始翻开 |
| 06-03 | 露出花瓣颜色，淡淡的橘 |
| 06-06 | 花苞松动，能看出层数不少 |
| 06-08 | 全开，直径约 8cm |

## 做对的三件事

1. **冬天没有剪太狠。** 去年我只剪掉了枯枝和交叉枝，保留了大量老枝——后来才知道这个品种是老枝开花，剪狠了就真的没有花。
2. **开春换了土。** 换掉了板结的旧土，加了约三成的松鳞。
3. **坚持每周一次薄肥。** 花苞期改成磷钾偏高的配方，浓度减半。

## 做错的一件事

五月中旬我为了"防病"，喷了一次浓度偏高的杀菌剂，结果新叶边缘焦了一圈。**预防性喷药一定要按最低浓度来**，植物比我们想的脆弱。

## 关于这一朵

我把它剪了下来，插在一个小玻璃瓶里，放在书桌边上。

切花其实有点可惜——留在枝上能开更久。但我更想在看书写字的时候一抬头就能看见它。养两年，值得换这十天。
